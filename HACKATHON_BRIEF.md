# Vibeathon 02: Night Shift | build brief

**Organizer:** Vibestarter. **Ecosystem:** Base. **Entry:** VERRIFT | the proof-of-fix network.

**Dates shown in the user-provided official-rules screenshots:** applications opened October 26 and closed November 2, 2026; building November 2-9, 2026; all deadlines 22:00 UTC. Judging and holder voting November 9-16. The actual live URL and submission must be provided before the build window closes.

**Judging weights:** Execution 30%, Launch potential 25%, Originality 20%, Craft/UX 15%, Vibecoding leverage 10%.

**Holder vote:** $VIBES holders vote as an additional scorecard, weighted by wallets' held/staked tokens; don't promise a specific score or outcome. Purchases aren't required for the product.

**User story:** A solo developer can open a repair case, capture a failing assertion, change the service, show a passing rerun, and optionally anchor evidence and settle testnet reward without trusting a decorative dashboard.

**Acceptance criteria:** signed-in data persistence; actual HTTP checks; no unverified external scans; repeatable fail/pass evidence; Claude API optional and fail-closed when unconfigured; a real Base Sepolia wallet transaction (not fabricated) with independent receipt check; responsive polished UX; docs/README; verified tests; honest limitations.

**Non-goals:** real-money escrow, production-grade pen-testing, arbitrary visual browsing, full GitHub PR write access and multi-tenant paid SaaS. Those are future-stage developments, not unfinished MVP claims.
