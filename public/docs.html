01 / PROTOCOL

The proof-of-fix sequence.

Create: Register a case with a fixed path, expected HTTP response and optional required text. Criteria cannot be silently edited between checks.

Capture: Run the check. Each observation includes the actual HTTP status or sample-service state, pass/fail assertions and timestamp.

Repair: Change the website or, for the built-in sample target, restore its actual service state.

Verify: Run again. A case is marked “verified” only after at least one recorded failed check and a later passing check against unchanged criteria.

Reward: Configure a developer's wallet, initiate a Base Sepolia test ETH payment, and verify the confirmed receipt using an independent RPC request.

02 / TARGET SAFETY

Only what you own.

Before external checks, prove domain control by publishing a TXT record at _verrift-challenge.yourdomain.com with a generated token or a token file at the website's HTTPS well-known path.

All external checks are read-only HTTPS GET requests. VERRIFT rejects IP-address targets, private network resolutions, local names, custom ports and redirects; checks are pinned to publicly resolved DNS addresses and have byte/time ceilings. It does not attack, discover vulnerabilities, or execute arbitrary scripts.

The built-in sample target is a deterministic API contract. Authenticated users can change its persisted state and record actual passing or failing checks.

03 / ASSISTED REASONING

Claude interprets. Tests decide.

The server sends a bounded set of recent case observations to Anthropic's Messages API using your own private ANTHROPIC_API_KEY. The key is never sent to the browser. Claude can outline likely causes, repair hypotheses and verification steps, but cannot mark a case fixed.

Without a configured API key, the application remains operational and the analysis action reports a clear configuration error. Live Anthropic calls incur provider charges.

04 / ONCHAIN SETTLEMENT

Base is the receipt.

Connect your wallet and authenticate with an EIP-4361 signature, switch to Base Sepolia (chain ID 84532), and send a specified quantity of test ETH directly to the developer. The server verifies the confirmed transaction's status, sender, recipient and exact value against the case reward before recording it.

Important: Test ETH has no intended monetary value. These transfers are non-custodial, direct and irreversible; there is no smart-contract escrow, jury dispute system, mainnet funding, audit certification or token sale in this MVP. VERRIFT never requests a private key.

05 / UNDER THE HOOD

Minimal dependencies. Real operations.

A Node.js 22 HTTP service powers Supabase Web3 wallet authentication, domain proof, pinned HTTPS checks, event history, Anthropic analysis and RPC verification. The interface uses accessible HTML/CSS and small browser modules. Data persists to an atomic local JSON file for development or Supabase Postgres in production, using a server-only state record. A Vercel serverless entry is included.

Run locally:

npm run setup
npm run dev
# open http://localhost:3000

See the repository README for full deployment instructions and required secrets.

06 / REALITY CHECK

What it doesn't do.

VERRIFT does not currently perform full visual browser journeys on arbitrary websites, execute GitHub patches, provide audited escrow contracts, or autonomously diagnose every class of bug. Wallet authentication is handled through Supabase Web3 authentication. External cases check HTTP status/text only. The controlled test target is available only to authenticated wallet accounts.

Production deployment requires Supabase Auth and Postgres, a session-signing secret, and the bundled SQL schema. Visitors can read the landing page without connecting. Creating cases, changing the test target and viewing private workspace data require a verified wallet session. Live Anthropic and Base RPC calls require internet access and account/wallet setup.

07 / PROJECT THESIS

From shipping faster to fixing better.

AI-assisted development accelerates launch velocity, but the work of fixing regressions remains poorly evidenced. VERRIFT is a small, focused experiment in accountability: an observed failure, a repeatable acceptance condition and a verifiable settlement.
